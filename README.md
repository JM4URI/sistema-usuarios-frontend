# Frontend – Sistema de Gestión de Usuarios

Interfaz web construida con **React**, **Vite** y **Material UI** para interactuar con la API del Sistema de Gestión de Usuarios.

## 🚀 Características

- Inicio de sesión con autenticación basada en token.
- Redirección automática al login si no hay sesión activa.
- CRUD de usuarios (crear, leer, actualizar, eliminar).
- Paginación de usuarios en pantalla.
- UI moderna y responsive con Material UI.
